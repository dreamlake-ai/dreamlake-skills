# Reopen work in Threads

Use the signed-in browser and the account that saved the Thread. Open the
selected organization's **Threads** list. To save the current panels under
a new name, use the command palette. To return, open that saved Thread.

```text
/new thread Launch review
/thread Launch review
```

If you already have a canonical Thread link, use it. When the installed CLI
advertises `dl threads --help`, use its link command to hand off a known
Thread ID or an organization's Threads list. Follow the
[terminal sessions reference](../reference/cli-sessions.md) for syntax and
availability. A link is not evidence that the Thread exists in this browser.

Use the **Sessions** entry for native sessions. Resume a runtime only when
the user requests it. Use the Thread's three-dot menu to archive or restore
work. If browser access is unavailable, give the user the verified source
session and document links. Report whether you saved a Thread or prepared
links.
