# Reopen work in Threads

Use the signed-in browser and the account that saved the Thread. Open the
selected organization's **Threads** list. Membership in the organization
alone does not make another user's browser-saved Thread available. To save the current panels under
a new name, use the command palette. To return, open that saved Thread.

```text
/new thread Launch review
/thread Launch review
```

If you already have a canonical Thread link, use it. When the installed CLI
advertises `dl threads --help` or the local MCP adapter advertises
`thread_open_url`, use the advertised schema to build a link for a known
Thread or organization. A link is not evidence that the Thread exists in
this browser.

Opening a Thread restores its panels. Start or resume a native terminal
through **Sessions** when the user requests it. Use the Thread's three-dot menu to archive or restore
work. If browser access is unavailable, give the user the verified source
session and document links. Report whether you saved or reopened a Thread, or prepared links.
