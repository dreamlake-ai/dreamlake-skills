# Author DreamLake Artifacts

When creating or repairing an artifact file, choose its kind, make it self-contained for DreamLake’s sandbox, and check its rendering constraints. Start with [create content](./references/create-content.md) and apply the matching kind template. If the artifact needs shareable query or fragment state, read [route-aware artifacts](./references/route-aware-artifacts.md). Publish through [dreamlake-artifacts](../dreamlake-artifacts/SKILL.md).
