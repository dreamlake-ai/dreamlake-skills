The product and CLI documentation are published. References were generated by
`scripts/sync_references.py`, not edited by hand:

- Two product pages: authoring and resource tools, version `0.1.114 594d5f21`.
- Two agent CLI pages and all 61 `dreamlake-cli` dependency pages: version
  `0.104.0 b385675`.
- Required closure: `dreamlake-agents` and `dreamlake-cli`. Both copies were
  installed from this branch into a fresh temporary project's `.agents/skills`
  and `.claude/skills`, and the installed skill was read back byte for byte.

  command-help preflight. SDK-only requests use the published TypeScript example.
- Online and offline checks passed with pytest installed. The optional scene
  suite skipped because its declared dependency was absent. All 55 script tests
  passed. A local package check verified the new catalog entry and both product
  references plus the CLI dependency in the archive.

Both acceptance processes used the same three requests and only local reads.
Codex used its read-only sandbox with user configuration disabled; Claude used
plan mode and restricted Read/Glob/Grep with no MCP servers. Both exited 0
within bounded deadlines. No permission bypass or resource mutation was used.
