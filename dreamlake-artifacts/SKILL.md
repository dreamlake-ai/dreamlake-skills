# DreamLake Artifacts

Use the DreamLake CLI for artifact operations. Choose the task guide that matches the request: [publish](./references/publish.md), [list](./references/list-artifacts.md), [manage sharing and access](./references/sharing-and-access.md), [remove or restore](./references/remove-and-restore.md), or [reference an artifact from Notes](./references/notes-references.md). The publish guide begins by checking CLI help and authentication before any write.

Artifact content must render in the isolated offline frame. If you are creating or changing the file itself, use [dreamlake-artifact-authoring](../dreamlake-artifact-authoring/SKILL.md) first.
